# 천기누설 · AI 관상 운세 (모바일 웹앱 / PWA)

스마트폰 카메라(WebRTC)로 얼굴을 실시간 스캔해 **Google MediaPipe**로 이목구비·표정 수치를 추출하고, **오늘의 명리학 일진(60갑자·오행)**과 결합해 유쾌한 관상 운세를 풀어주는 모바일 최적화 웹앱입니다.

## 주요 기능

1. **1단계: 실시간 얼굴 인식 및 특징 추출 (프론트엔드)**
   - Google MediaPipe Face Landmarker(478개 랜드마크 + 52개 표정 Blendshapes)가 브라우저(기기) 내에서 직접 실행됩니다. (영상은 외부 서버로 전송되지 않습니다.)
   - **추출 항목**: 미소 지수, 표정·긴장도, 얼굴형(계란형/둥근형/각진형/긴형/하트형/역삼각형), 삼정(상정·중정·하정) 비율, 눈꼬리 각도, 눈썹 형태, 재백궁(코) 비율, 좌우 대칭도.
   - **실시간 몰입 피드백**: 스캔 도중 *"현재 미소 지수가 82%! 복이 굴러들어오는 대길 표정이에요"*, *"오늘 눈꼬리가 살짝 올라간 걸 보니..."* 등 실시간 관상 코멘트와 황금빛 AR 오버레이를 표시합니다.
   - **카메라 대안 지원**: 전면/후면 카메라 전환, 갤러리 셀카 업로드 분석, 샘플 관상 즉시 체험.

2. **2단계: 관상 + 명리학 운세 생성**
   - 오늘 날짜의 실제 **60갑자 일진(천간·지지)과 오행(목·화·토·금·수)**을 자동 계산하고, 추출된 얼굴 수치와 조합해 관상 프롬프트를 구성합니다.
   - **내장 관상·명리 엔진**: 별도 API 키 없이 즉시 총운·재물운·연애운·직장/학업운·건강운·개운 처방전을 생성합니다.
   - **Gemini AI 연동 (선택)**: 우측 상단 설정(⚙️)에서 본인 Gemini API 키를 입력하면 실시간 LLM 생성 운세로 전환할 수 있습니다.
   - **운세 카드 저장/공유**: 결과 화면에서 스마트폰용 관상 카드를 이미지로 저장하거나 카카오톡·인스타그램 등으로 공유할 수 있습니다.

## 스마트폰에서 실행하는 방법

### 방법 1. 같은 Wi-Fi에서 PC 서버로 바로 접속 (HTTPS 필수)
스마트폰 브라우저(iOS Safari, Android Chrome)는 **보안 정책상 HTTPS 주소에서만 카메라(WebRTC) 권한**을 허용합니다.

```bash
npm install
npm run dev:https
```

1. 터미널에 표시되는 `Network: https://192.168.x.x:5173` 주소를 스마트폰 브라우저에 입력합니다.
2. 자체 서명 인증서 경고 화면이 나오면 **"고급" → "안전하지 않음(계속 진행)"**을 눌러 접속합니다.
3. 카메라 권한을 허용하고 얼굴을 비추면 바로 스캔이 시작됩니다!

### 방법 2. 무료 정적 호스팅으로 배포 (가장 편한 스마트폰 사용)
`npm run build`로 생성되는 `dist/` 폴더를 **Vercel**, **Netlify**, **Cloudflare Pages** 등에 올리면 정식 HTTPS 주소가 즉시 발급되어, 인증서 경고 없이 스마트폰 홈 화면에 앱처럼 추가(PWA)해 사용할 수 있습니다.
