# 매일 관상 운세 (모바일 웹앱 / PWA)

오늘의 얼굴 상태(미소, 표정, 눈매, 얼굴형 등)와 이름, 성별, 생년월일, 오늘 일진(60갑자·오행)을 정밀 분석하여 **사업·직장, 재물·금전, 연애·인연, 학업·성취, 건강·컨디션** 5대 운세를 쉽고 친근하게 알려주는 스마트폰 최적화 웹앱입니다.

- **실시간 실행 URL (스마트폰 접속)**: https://lucky7lee.github.io/unse/
- **GitHub 저장소**: https://github.com/lucky7lee/unse

---

## 주요 기능 및 특징

1. **성명, 성별, 생년월일 자동 저장 & 유지**
   - 성명 옆에 성별(남성/여성) 선택 및 년·월·일 콤보 박스 지원.
   - 한번 입력한 개인 정보는 브라우저 로컬 저장소(`localStorage`)에 안전하게 보존되어 매번 다시 입력할 필요가 없습니다.
   - 정보가 미입력된 상태에서는 먼저 입력을 친절하게 안내합니다.

2. **얼굴 정면 포착 5초 정밀 스캔**
   - Google MediaPipe AI가 얼굴이 화면 정면에 정확하게 포착되었을 때만 5초 카운트다운(5 → 4 → 3 → 2 → 1초)하며 스캔을 진행합니다.
   - 고개가 돌아가거나 흔들리면 안내 메시지와 함께 대기합니다.

3. **스캔없는 사주 명리 운세 모드**
   - 카메라 없이도 이름, 성별, 생년월일(사주 일주)과 오늘 일진의 십신(十神) 및 오행 상생상극을 분석하여 정밀한 하루 운세를 도출합니다.

4. **방대한 경우의 수 & 중복 없는 다채로운 운세 엔진**
   - 특성당 수백 개 이상의 한국어 현실 어휘 및 문장 풀(행운의 액션 300선, 주의점 300선, 카테고리별 다층 문장 뱅크 등)을 구축하여 **수만~수억 가지 이상의 유니크한 조합**을 생성합니다.
   - 같은 날에는 일관된 결과를 유지하되, **매일 날짜가 바뀌거나 얼굴 표정이 달라지면 완전히 새로운 결과**가 도출됩니다.
   - 어려운 전문 용어 대신 일상에서 공감할 수 있는 쉽고 실감 나는 구어체로 표현됩니다.

5. **개인정보 보호**
   - 카메라 영상은 외부 서버로 전송되지 않고 기기 브라우저 내부에서만 안전하게 분석됩니다.
