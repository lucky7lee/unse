# 매일 관상 운세 (모바일 웹앱 / PWA)

오늘의 얼굴 상태(미소, 표정, 활력)와 생년월일을 확인해 **사업·직장, 재물·금전, 연애·인연, 학업·성취, 건강·컨디션** 운세를 쉽고 친근하게 알려주는 모바일 웹앱입니다.

- **실시간 온라인 접속 주소**: https://lucky7lee.github.io/unse/
- **GitHub 저장소**: https://github.com/lucky7lee/unse

---

## 주요 기능

1. **성명 및 생년월일 자동 저장**
   - 한번 작성된 이름과 생년월일은 수정하기 전까지 브라우저에 안전하게 유지됩니다.
   - 성명과 생년월일이 입력되지 않으면 먼저 입력을 안내합니다.
2. **정면 포착 3초 실시간 스캔**
   - Google MediaPipe AI가 얼굴이 화면 정면에 정확하게 포착되었을 때만 3초간 카운트다운하며 스캔합니다.
   - 고개가 돌아가거나 정면을 벗어나면 안내 메시지를 띄우며 대기합니다.
3. **쉬운 우리말 5대 운세**
   - 어려운 전문 용어 대신 누구나 직관적으로 이해할 수 있는 친근한 표현으로 제공합니다.
   - 사업·직장운, 재물·금전운, 연애·인연운, 학업·성취운, 건강·컨디션운 및 오늘의 행운 팁.
4. **개인정보 보호**
   - 카메라 영상은 외부 서버로 전송되지 않고 기기 브라우저 내부에서만 안전하게 분석됩니다.
